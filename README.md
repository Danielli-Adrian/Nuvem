## Publicar no GitHub Pages

1. Crie um repositório público no GitHub.
2. Envie o arquivo `index.html` (e este README, se desejar) para a raiz do repositório.
3. Em **Settings → Pages**, selecione **Deploy from a branch**.
4. Selecione a branch `main`, pasta `/ (root)`, e clique em **Save**.
5. Aguarde a publicação e abra o endereço informado na seção Pages.

A página é independente: as imagens das logos e os estilos já estão incorporados no `index.html`.
